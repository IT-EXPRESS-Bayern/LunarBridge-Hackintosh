The Linux driver is NOT included as a macOS driver. No Linux kernel interfaces
or NootedGreen code have been transplanted into this prototype.
The functions implemented here include platform metadata and decoding plus
CPU-side GPU-VA ownership, Xe2 PTE encoding, page-table planning, GuC CSS/HXG/CT
validation and bounded shadow rings. Their format references also include
xe_vm.c, xe_pt.c, xe_pat.c, xe_ggtt.c, xe_uc_fw.c, xe_uc_fw_abi.h,
regs/xe_gtt_defs.h and the GuC message/CT ABI headers at the same source pin.
They do not allocate/bind native DMA pages, program GPU tables, authenticate or
upload firmware, run a scheduler, drive a display, compile shaders or provide
macOS Metal. Actual GMD_ID has NOT been read.

The additional Main-GT forcewake implementation uses hardware definitions and
protocol references from MIT-licensed xe_force_wake.c/.h (Copyright 2022 Intel)
and xe_mmio.c (Copyright 2021-2023 Intel). Its native IOKit adapter is own code.
The small xe_device_wa_oob.rules reference records the LNL platform association;
it has no individual SPDX header and is not republished as project source.
The adapter performs the four root dummy writes required before each LNL MMIO
read and, only with explicit forcewake opt-in, paired request/release writes.
Hardware MMIO and wake acknowledgements remain untested on native macOS.
No GGTT/PAT/firmware/engine programming or Metal implementation is added.

LunarLakePCIProbe.cpp uses separately licensed MacKernelSDK IOKit headers.
The SDK is an external build dependency. Its headers retain their own licenses.
Compiled object files are not executable or installable kexts.
