
# Contributing

Keep PCI recognition, GPU topology, display routing and macOS ABI adaptations
separate. A device ID or renderer name is not hardware acceleration evidence.

For every change record its source/license, affected hardware and test level:
source check, compiled object, synthetic execution or real native macOS device.
Preserve upstream copyright and SPDX notices. Do not import NootedGreen code
under a different license or claim rights to proprietary Windows/Apple drivers.

Do not commit installer images, driver binaries, firmware, ACPI machine dumps,
SMBIOS serials, Secure Boot private keys or local full hardware reports.
Proposed native boot changes must preserve the explicit Secure Boot requirement.
